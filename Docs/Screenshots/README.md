# Screenshots

Interface screenshots used by the root [README](../../README.md).

Captured from a development build of Quibble on macOS 26.6.1, at the window's
own size on a 2x display, with `screencapture -l<window id> -o -x`. The Home
image is cropped to the top card so that a real transcript is not published;
the others are whole windows.

Refresh these when the interface they show changes. Keep them free of dictated
text, history entries, and saved vocabulary that belong to a real person.
