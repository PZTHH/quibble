# Quibble build 17: native window, independent HUD materials, and online speech

Date: 2026-09-06. Signed local Release build 17.

## What changed

- **Native settings window.** Removed the rounded mask around the root content. On macOS 15 and later, SwiftUI's window container background supplies the material, and macOS draws the actual window frame and outer corners. The titlebar blends into that surface; fullscreen remains unavailable. Tahoe's native radius is system-owned, not a manually enforced 26-point content radius. The older macOS fallback is retained but was not visually tested here.
- **HUD layout and material are independent.** Studio, Strip, and Compact each support Solid or Frosted. Layout controls detail and interaction; material controls appearance. Legacy Glass becomes Strip with Frosted material during migration, while subsequent layout changes preserve the chosen material. Reduce Transparency overrides the rendering without erasing the preference. Compact remains passive, and noninteractive phases pass clicks through.
- **Lower, damped Soft cues.** Five original bundled sounds were regenerated using the supplied ElevenLabs audio as a tonal reference. Ordinary events use a short damped gesture; error has a low double pulse. Files are 120–265 ms, with no clipped samples and smooth endpoints. No reference samples were copied. These are measured spectral/envelope changes; perceived quality still needs the user's ears. See [sound measurements and generation](SOUND-REFINEMENT-2026-09-06.md).
- **Optional OpenAI transcription.** Models → Speech → Online transcription → Set up opens an explicit connection sheet. A key is stored in this Mac's Keychain. Saving it neither sends audio nor selects the provider. When explicitly selected in a mode, OpenAI receives the recording plus enabled literal vocabulary and language hints. Nearby application context is not included. Billing is separate from ChatGPT. Existing local writing steps remain available.
- **Workflow save reporting.** Candidate data is encoded and checked before replacing visible state. Corrupt archives are preserved, failed saves remain visible, and failed undo retains its recovery state. UserDefaults readback establishes acceptance by the preferences service; it is not an fsync guarantee.
- **Completed cleanup only.** S1 cleanup and instruction refinement require an explicit normal stop and usable output. Missing completion metadata, token exhaustion, and invalid output fail the writing stage so its input can be retained.

## Device load and provider boundaries

Selecting online speech skips loading primary local ASR weights. Vocabulary uses the provider's native keyword hints and any enabled explicit correction rules; it skips the local Whisper/S1 vocabulary helper path. Local cleanup or custom instructions still consume local resources if enabled. Existing idle unloading remains. No idle network polling or continuous listening was added. These code paths reduce local inference work; energy and latency improvements have not been measured.

The provider adapter uses a fixed HTTPS endpoint, canonical in-memory WAV uploads, an ephemeral session, bounded responses, cancellation, no redirects, and no automatic retries or fallback uploads. Error messages do not reflect provider bodies or keys. Keys are neither embedded in defaults nor added to history or traces. This build uses the existing Mac login Keychain with a restricted application ACL; credential access across future signed updates still needs an end-to-end test.

The request contract was checked against the current official [speech-to-text guide](https://developers.openai.com/api/docs/guides/speech-to-text) and [GPT Transcribe model documentation](https://developers.openai.com/api/docs/models/gpt-transcribe). It uses `gpt-transcribe`, `keywords[]`, and `languages[]`. No real key was entered and no real provider request was made during this pass. The connection needs a live API test before recommending it for daily use.

Current limits: actual cloud latency/accuracy/cost and vocabulary behavior, Keychain update continuity, fresh cross-app dictation coverage, HUD click-through across multiple displays, light appearance, and VoiceOver have not been fully exercised in this pass. The earlier user-confirmed shortcut/insertion result remains prior evidence.
