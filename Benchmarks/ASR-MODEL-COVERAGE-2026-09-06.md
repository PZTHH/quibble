# ASR model coverage and practical Apple Silicon additions

Retrieved: **2026-09-06**. Directional after: **2026-09-13**. All sources below were read on the retrieval date. This is a researched catalog and adapter assessment, not a claim that every checkpoint has passed an audio test in Quibble.

## Answer

Use one row for each actual model/checkpoint and put its weight variants in Details. Qwen3 ASR 1.7B and Cohere remain strong general choices; Qwen 0.6B and the smaller Whisper models are useful low-load options. Add Q8 alternatives to existing Q4 models before multiplying unrelated models. Native implementations already present in the pinned dependency make Canary, Nemotron, original Moonshine, Granite 4.0 and Voxtral Realtime practical integration candidates. A loader's presence proves neither successful weight loading nor acceptable dictation quality: ship a download only after its exact artifact runs through Quibble's audio path.

**Recommendation, not a measured memory policy:** choose a validated smaller quantization when memory is constrained; offer Q8 where it produces a useful quality/headroom tradeoff. Do not force Q4/Q8 onto every architecture. Original Moonshine is tiny enough in official FP32, the pinned Moonshine loader does not support quantization, and other native backends may recommend mixed or palettized weights. Disk size is not peak RAM. Keep the user's explicit choice and show the selected variant before downloading it.

## Benchmark evidence

The current public CSV has 62 models and eight English short-form public datasets. Its `avg` is the mean of those eight WER columns, including Voice Arena Monsoon. The Space's latest configuration also lists two private datasets; the public CSV does not establish an identical live ten-dataset score. Use the public scope in the UI and keep the date, exact evaluated checkpoint and limitations in Details. WER is not a probability that each word is correct, and a relative segmented Accuracy meter is not an absolute percent-correct score. Published RTFx is hardware/batching-specific throughput, not measured Mac latency or key-release-to-paste time. Q4/Q8 variants inherit an **upstream reference**, not an invented quantized WER measurement. A full multilingual decision needs the corresponding language evaluations and real dictation fixtures.

## Local adapter evidence and integration hazards

Source revision: [MLX Audio Swift `bf14ae0c26e4e85553dd989571cae29d70fa6735`](https://github.com/Blaizzy/mlx-audio-swift/tree/bf14ae0c26e4e85553dd989571cae29d70fa6735/Sources/MLXAudioSTT/Models), as pinned by `Inference/Package.swift`. Local Quibble observations refer to the working-tree files `Inference/Sources/QuibbleInference/LocalInference.swift`, `Inference/Sources/QuibbleWhisper/WhisperModel.swift`, `App/Resources/ModelCatalog.json` as read 2026-09-06; the implementation may change after this research.

- **Already integrated:** Cohere, Parakeet TDT v3, Qwen3 ASR 1.7B/0.6B, custom Whisper Turbo/Large v3/Small/Base. Q8 paths share supported architecture but still need exact-artifact load checks.
- **Canary:** `CanaryModel.fromModelDirectory` supports NeMo and MLX-native key remapping, embedded or sidecar SentencePiece, flat or per-layer quantization. The Mediform Q8 config uses the supported embedded tokenizer and `bits: 8` fallback to group size 64. Canary-Qwen is not that architecture.
- **Nemotron:** `NemotronASRModel.fromDirectory` explicitly supports the 3.5 Q8 conversion. It normalizes nonstandard Infinity/NaN config values and loads from the local folder. Use this path, not the repository-based downloader. The user-facing app still dictates on release; a streaming-trained ASR is not evidence that the app already supplies live partial results.
- **Moonshine:** original model loader accepts official safetensors and tokenizer.json, but has no quantization loader, streaming architecture, chunk handler or decoder cache. The original models are English-only here. Explicitly cap decoder tokens and split long audio through Quibble's outer audio reader; do not advertise adjustable chunk size that the backend ignores.
- **Granite:** documented existing architecture is Conformer + QFormer + autoregressive Granite decoder, with `granite-4.0-1b-speech-5bit` named in its README. **Its `language` argument requests translation into that language**, not recognition-language bias. ASR must call with no translation language/custom translation prompt. TurboCTC and NAR require separate compatibility work.
- **Voxtral:** only Realtime 4B architecture has a pinned model implementation. Its required `tekken.json` must be in the exact manifest. Mini 3B/Small 24B cannot use this loader just because the family name matches.
- **Vocabulary:** retain the existing guarded audio vocabulary pass until an ASR-specific hint method is independently validated. A model saying it supports prompts is not sufficient evidence that arbitrary name-list prompts only change intended words.
- **Quality/readiness:** real input must exercise first load, short transcription, silence, chunk boundaries, cancellation/unload and one long fixture without loops/truncation. Download test artifacts into a temporary validation root and keep them out of the user's installed model set. Validate one model at a time; record runtime, output and peak memory. No new weights were downloaded for this research-only snapshot.
